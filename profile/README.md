# Soma Labs

We build tools that read the body the same way every time, from Palo Alto. Some of them are open source.

## Open source

### [Open Health Sync](https://github.com/soma-intelligence/open-health-sync)

A self-hostable health data aggregator in Go. It collects Apple Health and Withings data, keeps every raw payload, normalizes it to one model with one set of units, and serves it back over a REST API and a read-only MCP server.

- One binary, Docker Compose, or a Raspberry Pi
- Postgres with TimescaleDB, raw payloads on disk
- Read-only MCP server so an AI agent can read your own data
- AGPL-3.0
